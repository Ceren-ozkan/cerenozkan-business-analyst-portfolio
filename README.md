# Junior Business Analyst Portfolio – Ceren Özkan

This repository contains business analysis case studies, SQL analysis examples, process documentation, user stories, acceptance criteria, and test scenarios prepared for Junior Business Analyst / IT Business Analyst roles.

## Portfolio Overview

The purpose of this portfolio is to demonstrate practical business analysis skills through realistic case studies.  
All case studies are fictional and created with dummy data. No confidential company or bank data is used.

## Case Studies

### 1. Mobile Banking Limit Management
A mobile banking feature analysis case focused on transfer limit visibility, limit increase requests, OTP verification, request tracking, and operational review.

**Skills demonstrated:**
- Requirement analysis
- User story writing
- Acceptance criteria
- Process flow design
- Test scenario preparation
- Banking feature analysis

### 2. Customer Transaction Analysis with SQL & Power BI
A data analysis case using dummy banking transaction data to answer business questions, write SQL queries, and generate dashboard insights.

**Skills demonstrated:**
- SQL querying
- Customer segmentation
- Dashboard planning
- Business insight generation
- Data-driven recommendation writing

### 3. Digital Credit Card Application Process
A process improvement case focused on digitalizing the credit card application journey and improving customer experience.

**Skills demonstrated:**
- Process analysis
- Current state / target state comparison
- User story writing
- Acceptance criteria
- Risk analysis
- KPI definition
