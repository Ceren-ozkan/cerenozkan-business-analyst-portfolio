# User Stories – Mobile Banking Limit Management

## User Stories

### US-01 – View Current Transfer Limits

As a retail banking customer,  
I want to view my current EFT, FAST, and internal transfer limits,  
so that I can understand my transaction capacity.

### US-02 – Request Limit Increase

As a retail banking customer,  
I want to request a limit increase through mobile banking,  
so that I do not need to visit a branch or call customer service.

### US-03 – Complete Security Verification

As a retail banking customer,  
I want to complete OTP or mobile approval verification,  
so that my request is processed securely.

### US-04 – Review Limit Requests

As a bank operations team member,  
I want to review limit increase requests,  
so that I can approve or reject them according to bank policies.

### US-05 – Track Request Status

As a customer,  
I want to track my request status,  
so that I know whether my limit request is pending, approved, or rejected.
